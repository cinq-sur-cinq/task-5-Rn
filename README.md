## Условие задачи

### Задание 5. Класс точки в Rⁿ с динамической размерностью

Реализовать функцию-фабрику `make_point_class(n, name=None)`, которая:

- Создаёт новый класс точки с ровно `n` атрибутами-координатами: `x0, x1, …, x(n-1)`.
- Управляет каждым атрибутом через экземпляр дескриптора `CoordDescriptor`, который
  проверяет, что значение — число (`int` или `float`), и вызывает `TypeError` при неверном типе.
- Создаёт конструктор, принимающий ровно `n` позиционных аргументов (координат).
- Добавляет метод `to_tuple()`, возвращающий координаты в виде кортежа.
- Кэширует классы через `functools.lru_cache`, чтобы повторные вызовы для одного `n`
  не создавали класс заново.

---

## Описание решения

В файле `Rn.py` реализованы дескриптор `CoordDescriptor` и функция-фабрика
`make_point_class`.

| Элемент | Назначение |
| --- | --- |
| `CoordDescriptor` | Дескриптор координаты: принимает только `int` и `float`, иначе вызывает `TypeError`. Имя атрибута для хранения задаётся через `__set_name__`. |
| `make_point_class(n, name=None)` | Создаёт класс точки в Rⁿ через `type()`. Если `name` не указан, класс называется `Point<n>`, например `Point3`. |
| `__init__(*coords)` | Принимает ровно `n` координат; при другом количестве вызывает `TypeError`. |
| `to_tuple()` | Возвращает координаты в виде кортежа `(x0, x1, …, x(n-1))`. |

Логические значения `True` и `False` не принимаются как координаты, хотя в Python
`bool` является подклассом `int`. Повторный вызов `make_point_class` с теми же
аргументами возвращает тот же самый объект класса благодаря `lru_cache`.

В конце файла приведены примеры создания класса и точки, проверки кэширования
и отклонения некорректных данных.

## Запуск программы

Требуется Python **3.8 или новее**. Виртуальное окружение и дополнительные
пакеты не нужны.

### 1. Клонируйте репозиторий и перейдите в папку задания

Скопируйте и выполните команды в терминале:

```bash
git clone https://github.com/cinq-sur-cinq/task-5-RN.git
cd task-5-RN
```

### 2. Запустите программу

macOS/Linux:

```bash
python3 Rn.py
```

Windows:

```powershell
python Rn.py
```

Программа автоматически выполнит примеры и выведет результаты:

- Имя созданного класса: `Point3`.
- Значение координаты `x2` точки `(1, 2, 3.5)`: `3.5`.
- Координаты точки в виде кортежа: `(1, 2, 3.5)`.
- Проверка кэширования: `True` для того же `n`, `False` для другого `n`.
- Имя класса, заданное вручную: `Vector`.

Сообщения `Rejected: ...` в конце вывода — ожидаемые результаты проверок
неверного количества координат, нечислового значения и логического значения.
